# sandbox/experiments/ — 实验区

> 一次性的试跑、验证性脚本与 notebook。**这里的东西默认不是项目的一部分。**

## 什么该进来

- 验证某个想法是否可行的最小脚本
- 一次性的对比测试、探针、benchmark 试跑

## 什么不该进来

- 已经确定要长期维护的代码 —— 那属于正式目录
- 可复用的工具脚本 —— 那属于 `ai_system/scripts/reusable/`

## 出口

- **验证成功** → 把结论与提炼后的代码移进正式目录，实验本体进 `_archive/`
- **验证失败** → 直接进 `_archive/`（失败结论本身有价值，别删）
