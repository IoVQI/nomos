# sandbox/ — 沙箱

> 未定型东西的落地区：实验、草稿、从别处扒来待本地化的组件。
> 这里的东西**默认不是项目的一部分** —— 本地化、提炼、定型之后才进正式目录。

## 与协调设施的分工

本目录**不含**并行声明与交接协议。那两类是治理设施，见 [`coordination/`](../coordination/README.md) ——
早期项目曾把它们埋在 `sandbox/` 下（`_parallel/`、`_handoff/`），本骨架已明确提升出去。
同理，可复用脚本在 [`ai_system/scripts/reusable/`](../ai_system/scripts/reusable/)，不在本目录。

## 子目录

| 目录 | 放什么 | 生命周期 |
|------|------|------|
| `external/` | 从其他项目扒来的组件，待本地化进 Nomos | **本地化完成即删原件**（元信息留存，见其 README） |
| `experiments/` | 一次性试跑、验证性脚本与 notebook | 定型 → 提炼进正式目录；否则进 `_archive/` |
| `drafts/` | 未定型的写作、设计草稿 | 成稿 → 进 `project/`；否则进 `_archive/` |
| `_archive/` | 上面三者废弃后的归档区 | 只进不出 |

命名沿用原项目约定：**下划线前缀 = 基础设施，无前缀 = 内容件**。

## 进 version control 吗

- `external/staging/` —— **不入库**（规则见根 `.gitignore`）：克隆件自带嵌套 `.git`、
  体积大、版权属第三方。该目录下仅 `README.md` 被显式放行。
- `external/_registry/`、`external/_index.md` —— **入库**：它们是那段代码唯一的溯源痕迹，
  尤其因为原件在本地化后即删。
- 其余子目录按正常规则入库。

## 本目录的边界

沙箱里的一切**默认可以随时删除**。若某样东西删掉会造成损失，说明它已经定型了 ——
那就该把它移进正式目录，而不是继续留在沙箱里。
