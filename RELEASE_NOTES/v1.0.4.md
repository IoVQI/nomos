# Nomos v1.0.4

**Release date / 发布日期**：2026-10-20

## 中文

本次发布对发布件做**全面通用化**，并重建公开仓历史。

### 变更

- 移除原项目的具体研究标识与内部路径（项目结构名、模型/求解器专名、案例名、内部台账路径）。
- `ai_system/rules/coding_rules.md` 重写为通用科研编码规范：单位纪律、验证闸门、回归测试、
  可复现性与禁止做法。
- `workflow_usage_guide.md` 重写为简洁的通用选择指南。
- 删除已废弃或项目特定的工作流（`session_report_workflow.md`、
  `portability_refactor_workflow.md`），同步更新注册表与引用。
- 新增可选 `records/` 台账骨架：备忘录、报告、会话摘要。
- 公开仓历史重建为**单个提交**；提交作者与标签均使用 GitHub noreply 身份。

### 安全说明

- 旧公开仓的提交/标签元数据中曾包含个人邮箱；本次重建已移除。
- 旧 tag 中的内部路径与项目名不再存在于新历史。
- 发布件经敏感信息、个人路径、内部路径与公开卫生闸门扫描，均 0 命中。

## English

This release generalizes the public artifact and rebuilds the public history.

### Changed

- Removed source-project research identifiers and internal paths (project layout names,
  model/solver-specific names, case names, internal ledger paths).
- Rewrote `ai_system/rules/coding_rules.md` as generic scientific coding rules: units,
  validation gates, regression tests, reproducibility, and forbidden practices.
- Rewrote `workflow_usage_guide.md` as a concise generic selection guide.
- Removed deprecated or project-specific workflows (`session_report_workflow.md`,
  `portability_refactor_workflow.md`) and updated the registry and references.
- Added an optional `records/` ledger skeleton (notes, reports, session summaries).
- Rebuilt the public history as a **single commit**; commit author and tags use a GitHub
  noreply identity.

### Security

- The previous public history exposed a personal email in commit and tag metadata;
  the rebuild removes it.
- Internal paths and project names from old tags are not present in the new history.
- The release passed secret, personal-path, internal-path, and public-hygiene scans
  with zero findings.
