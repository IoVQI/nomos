# ai_system/official_docs/ — 上游文档链接清单

> **本目录不镜像、不再分发第三方文档，只保留链接与用途说明。**

## 为什么

官方文档（Claude Code、DeepSeek API、各类 harness）的版权归各提供方所有。
把整站镜像复制进仓库既增加体积，也可能违反再分发条款，且很快过期。

**做法**：需要时直接查阅上游；本目录只登记「看什么、为什么看」。

## 入口

- Claude Code 文档：<https://code.claude.com/docs>
- Claude Agent SDK：<https://docs.claude.com/en/api/agent-sdk/overview>
- Anthropic API：<https://docs.claude.com/en/api/overview>
- DeepSeek API：<https://api-docs.deepseek.com>

## 使用约定

1. 引用官方文档时，写**链接 + 访问日期 + 结论**，不要大段复制原文。
2. 若确需本地缓存（离线环境），放在仓库外，并在 `.gitignore` 中排除。
3. 文档变更导致工作流失效时，按工作流自身的审计流程处理，不要把镜像当作版本真源。
