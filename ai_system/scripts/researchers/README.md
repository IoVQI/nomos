# ai_system/scripts/researchers/ — 研究辅助脚本（不随发布件分发）

> 本目录在开发仓中承载 arXiv / INSPIRE / Semantic Scholar 的元信息抓取脚本。
> **这些脚本与具体研究领域强绑定，不属于治理骨架，故不随公开发布件分发。**

## 如果你需要类似能力

1. 从你使用的文献服务商获取 API Key，放在环境变量中，**不要写入仓库**；
2. 脚本从 `os.environ` 读取密钥；
3. 遵守服务商的速率限制与使用条款；
4. 抓取结果（元数据、PDF）不要提交到仓库。

## 为什么保留这个目录

保留路径与说明，避免 `ai_system/index.md` 等索引出现死链接；目录内不含可执行脚本。
