# 复现绘图规范 — 可复用模式与默认展示窗口

> 约束「从复现结果到成品图」的流水线：输入契约、目录语义、计算与绘图分离、标准图集、
> 统一样式与默认展示窗口。目标是让同一套绘图设施能跨实验组、跨项目复用，
> 让图能追溯回数据，让不同人对同一结果看到同样的窗口。
>
> 本准则是判断层文件：不绑定具体论文、软件或物理量。文中「案例 A / 案例 B」仅表示两类
> 复现项目——单组精细复现与批量扫描复现——用于说明模式，不是任何人项目的记录。

---

## §1 两类复现项目对照

| 维度 | 案例 A：单组精细复现 | 案例 B：批量扫描复现 |
|------|------|------|
| 绘图入口 | 单个标准绘图脚本 | 批量脚本 + `--mode` 模式参数 |
| 图集规模 | 固定图集（强制生成） | 多种模式，按分析目标选择 |
| 输入契约 | 每组一份标准数据文件组合 | 批量缓存（一个实验一个文件） |
| 扫描轴识别 | 目录名编码扫描参数 | 运行目录 + 显式参数 |
| 执行架构 | 直接读实际实验组目录 | 计算 → 保存 → 绘图三步分离 |
| 样式 | 项目统一 figstyle | 内置调色板 |
| 编目 | 产物索引（组 ↔ 图 ↔ 数值） | 产物目录 + 元数据 |
| 论文对比 | 参考点/曲线叠加 | 基准锚点叠加 |

两类不是互斥的：单组项目在实验数量上来后会演化成批量项目；批量项目也需要单组精细核查。

## §2 可复用模式

### P1 输入契约标准化

- 每个实验组 = **固定命名的标准数据文件**（主数据 + 派生数据 + 基准数据）。
- 绘图脚本**只读标准输入、不重算物理/模型** → 一个通用脚本可跨实验组复用。
- 契约写在实验组 README 或 schema 文档里；字段名只在一处定义。

### P2 目录命名携带语义

- 目录名编码扫描参数（如 `<前缀>_<参数名>{值}_{方法}`）。
- 绘图脚本解析目录名 → 自动判定坐标轴、自动排除交叉核验目录。
- 新复现须约定「目录命名 = 扫描参数」规则，避免手工传参遗漏。

### P3 计算—保存—绘图三步分离

- 重计算（模型/求解器）与绘图解耦：Step 1 生成主数据 → Step 2 派生量 → Step 3 绘图。
- 绘图读缓存秒出 → 迭代样式/图集时无需重算。
- 缓存文件须带版本或参数指纹，避免用旧缓存画新结果。

### P4 标准图集约定（强制）

- 定义每个实验组**必须生成的图集**，覆盖该领域判断完整性所需的核心视图。
- 图集清单写入实验组 README，生成时强制产出，防止遗漏。
- 新增图是加分项，不能替代标准图集。

### P5 统一样式

- 项目统一调色板、字体、网格、线宽（`figstyle.apply_style()` 一类入口）。
- 跨脚本、跨汇报材料使用同一套样式；样式变更视为全局变更，须全量重渲染。
- 图注格式（来源、置信度、单位）由样式层统一，不逐图手写。

### P6 扫描参数的颜色映射

- 一图多曲线时，用**有序色带**（浅→深，单色系）+ colorbar 编码连续扫描参数。
- 离散分组时用可区分色板，并保证色盲友好。
- 图例与色带择一，不重复编码同一信息。

### P7 产物编目登记

- 每个实验组有产物索引：实验组、图集、关键数值、生成时间、脚本版本。
- 图随组存放；产物可追溯到输入与脚本。
- 编目是生成物时，不手写第二份。

### P8 论文数据叠加对比

- 把论文参考点/曲线叠加到复现图上，直观显示符合性。
- 参考数据须注明来源（原文表格/数字化/作者提供）与置信度。
- 叠加层与复现层样式可区分，图注说明各自来源。

### P9 CLI + Python API 双入口

- 命令行入口（`--run-dir` / `--mode` / `--output`）保证可复现。
- 可导入 API 供管线与批量任务嵌入。
- 两者共享同一实现，不维护两份绘图逻辑。

### P10 轴标注与默认展示窗口

- 单位统一并写在轴标签上；log 轴须标注底数。
- 物理/领域参考线（边界值、典型值、观测约束）以虚线或注释标出，并在图注说明。
- **默认展示窗口**是先验约定，不是每次临时调参。建议按图型定义：

| 图型 | 默认窗口 | 依据 |
|------|---------|------|
| 全域关系图（log 横轴） | 覆盖输入数据的完整有效域 | 不截断低端/高端；异常区可见 |
| 核心区放大图 | 由领域典型区间界定 | 与全域图成对出现，图注说明放大范围 |
| 比值/残差图 | 以 0 或 1 为中心，上下界覆盖噪声与系统偏差 | 便于判断偏离方向和量级 |
| 参数扫描图 | 固定扫描轴范围，不随单次结果自适应 | 保证不同实验组可横向比较 |
| 论文对比图 | 与原文图相同的窗口 | 避免「换窗口后看起来一致」 |

> 新复现先对齐默认窗口；论文特定动态范围再按需调整，并在图注或 README 说明调整理由。
> 默认窗口本身是版本化约定：变更时须重渲染受影响的图。

## §3 项目特定部分（不可直接复用）

以下内容随项目变化，推广时替换为新项目的对应物，不动 §2 的模式骨架：

| 特定项 | 说明 |
|------|------|
| 命名前缀 | 扫描参数编码方式、运行目录命名规则 |
| 参考数据 | 论文表格、观测约束、基准锚点的具体来源 |
| 图集侧重 | 该项目最关心的图型与面板组合 |
| 样式 | 项目色板、字体、期刊/会议模板 |

## §4 应用指引

新复现实验组落地流程：

1. **定义输入契约**：确定主数据、派生数据、基准数据的标准文件名与 schema。
2. **约定目录命名**：`<日期>_<描述>/<前缀>_<参数>{值}_{后缀}/`，后缀编码扫描参数。
3. **定义标准图集**：先覆盖完整性所需的核心视图，再添加项目特定图。
4. **统一 figstyle**：复用项目样式入口，不逐脚本复制样式代码。
5. **编目登记**：产物索引记录实验组、图集、关键数值与脚本版本。
6. **强制生成**：图集随实验组生成，README 写入约定防遗漏。
7. **默认窗口**：按 §2 P10 的表对齐；调整须留理由。
