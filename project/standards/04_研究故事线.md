# 研究故事线 — 研究叙事主线的必备内容与逻辑顺序（九节点）

> 本准则定义**研究的故事线（storyline）**：一项研究作为一段叙事，其**因果主线**是什么。
> 它回答「**这项研究为什么成立、是怎么一步步被证明的**」，独立于「怎么呈现」而存在。
>
> 一个合格的故事线通常具备：完整的起点、可判定的问题、可信的工具、收敛的证据、
> 对替代解释的排除，以及诚实的结论边界。反过来，如果一项研究从头到尾只有一条
> 「方法 → 结果 → 结论」的直线，它大概率缺少自证、排除或边界，故事线并未立住。

---

## §0 先划清概念：故事线 vs 叙事弧

这是本准则最核心的概念区分——故事线不是「叙事弧」的同义词，而是它的**上游**。

| 维度 | 故事线（Storyline，本准则） | 叙事弧（Narrative Arc） |
|------|------|------|
| 对象 | 研究**本身**的因果主线 | 一份**呈现/汇报**的组织顺序 |
| 回答 | "为什么成立、怎么一步步证明的" | "怎么讲才完整、顺序才对" |
| 组织序 | 因果序（先自证，后立论） | 说服序（先亮结论，再证据链支撑） |
| 时机 | 随研究推进**同步涌现** | 成果成熟后、汇报前 |
| 关注 | 因果逻辑 / 证据强度 / 确定性刻度 | 顺序完整性 / 冗余 / 归组 |
| 责任工作流 | 本准则 | 汇报叙事审计工作流（若你的项目有） |

**关系**：故事线是**里的**（研究做了什么、为什么成立），叙事弧是**表的**（把故事线按汇报顺序重新组织）。
同一条故事线可被不同叙事弧组织；但叙事弧缺了故事线，就只剩章节顺序而没有因果。
**故事线先于叙事弧存在。**

## §1 必备内容：九节点

> 每个节点 = 一个叙事节拍。括号内是在该节点必须回答的**判别问题**——答不出，说明该节点未立住。

| # | 节点 | 功能：它给故事线提供什么 | 必备内容 | 判别问题 |
|:--:|------|------|------|------|
| ① | **钩子/现象** | 建立"为什么值得追" | 一个**具体、非平凡、可验证**的签名/现象（是什么、在哪、多显著）+ 若为真意味着什么 | "我能一句话指认它吗？它为真有何分量？" |
| ② | **问题化** | 立可判定的输赢 | 把现象转成一个**可判定**的科学问题 + **预设分叉**（若 A → 做 X；若 B → 做 Y） | "什么叫'回答了这个问题'？输赢标准写死了吗？" |
| ③ | **自证可信** | 排除"工具错了" | 用**独立基准**交叉校验工具/复现/代码（如与原文可观测量、与第三方求解器一致） | "在信任结果前，我怎么证明我的工具不是错的那一方？" |
| ④ | **首次发现** | 给排除提供靶子 | 初判结果 + 把与现象的差异**精确定位**到点/量（差多少、差在哪） | "异常只在哪一个点/量上？还是一团浆糊？" |
| ⑤ | **逐级排除** | 承重证据链 | **穷尽替代解释**（每个嫌疑方向单独受控检验）+ 两侧证据在**同一量纲**收敛 | "每个其他可能都被单独堵死了吗？证据是不同路径收敛到同一结论吗？" |
| ⑥ | **机制/深层解释** | 把负结果升级为理解 | 不止"没有"，还要"**为什么**"——给出**可测试机制假说** + **数值指纹吻合** | "'不是 X'能不能进一步升级成'它其实是 Y'？" |
| ⑦ | **诚实弧线** | 可信度的来源 | 诚实呈现结论**如何演变**（含反转）+ 为何最终如此 | "我敢把自己的反转写进结论吗？" |
| ⑧ | **结论与边界** | 给结论强度刻度 | 判定 + **严格措辞** + **边界声明**（什么算证明了、什么只是强排除/推断） | "我说的话，哪些是我证明的、哪些只是排除下的推断？" |
| ⑨ | **动作与留白** | 诚实收束 | 残留动作 + 明确**尚未回答**的 + 外部才能办的 | "我明确承认了还有什么是未知的/要留给别人的吗？" |

**贯穿纪律**（不属某一节点，但决定故事线是否可信）：

- **事实—叙述分离**：故事线只是把**已证明**的事实重排成因果链，绝不反过来为叙事编造事实。
- **数据从源文件重提**：每个数值引用自本地产物/源报告，不凭记忆。
- **负结果也有"为什么"**：不允许以"复现不出来/没效果"草草收尾——必须写"穷尽了什么、排除了什么、还剩什么"。

## §2 必要的逻辑顺序（哪些必须前置，哪些必须延后）

顺序纪律是故事线成立的地基。四条硬约束：

1. **问题化先于一切探索**（② 在 ① 之后、④ 之前）
   - 必须先立"判定标准"，否则后面全是"讨论了但没结论"。
   - 反例：研究做了一大半才补写"怎样算成功"，此前的实验全部无法判定。

2. **自证可信先于首次发现结果**（③ 严格先于 ④）
   - 工具未证明可靠之前，结果无论对错都不可信。这是**最常被跳过、也最致命**的一条。
   - 反例：复现结果与原文不符，却未先确认自己的求解器/管线是否正确，直接把差异归因于原文。

3. **逐级排除先于最终结论**（⑤ 先于 ⑧）
   - 先堵住替代解释，再下判定。判定若早于排除，会被"是不是忽略了 X"一击即溃。
   - 反例：结论写成"机制是 Y"，但从未检验过 Y 之外的解释。

4. **机制解释在排除之后**（⑥ 在 ⑤ 之后）
   - 先排除"不是什么"，才能谈"是什么"；先有收敛的排除结果，机制定位才有地基。
   - 反例：先编一个机制故事，再挑对故事有利的证据。

**软约束**（合理但可弹性）：

- ⑦ 诚实弧线通常贴近结论（⑧），因为它解释了"最终为何如此"——但也可能在⑤/⑥内穿插（发生在排除过程中）。
- ⑨ 动作与留白在最后（⑧ 之后），先把判定收敛，再开放。

> **一句话顺序纪律**：*先让它值得追 → 再立怎么判定 → 再来证明工具可靠 → 才敢下初判 →
> 才去堵替代解释 → 才能谈机制 → 诚实呈现演变 → 精确定刻度 → 诚实留余。*

## §3 可复用结构骨架（把节点写成章节时的默认标题）

> 快速落地：把一份研究按此骨架展开，每节对应一个节点。命名可随学科调，但功能不增减。

```text
## 1. 现象与问题          （①+②：钩子 → 可判定的问题 + 分叉）
## 2. 方法与自证          （③：管线/复现 + 与独立基准的交叉校验）
## 3. 结果与差异定位       （④：初判 + 异常定位到点）
## 4. 逐级排除与证据链     （⑤：嫌疑逐一排除 + 双侧收敛）
## 5. 机制与深层解释       （⑥：为什么 —— 假说 + 指纹吻合）
## 6. 结论演变与诚实弧线   （⑦：判定如何反转/回稳）
## 7. 结论与边界          （⑧：判定 + 严格措辞 + 边界）
## 8. 动作与留白          （⑨：残留 + 未知 + 外部）
```

## §4 把负结果写出故事力的杠杆点

负结果不是失败记录。三个杠杆把它变成有分量的科学判定：

1. **把"没有"换成"排除了什么"**
   - ✗ "我复现不出这个结果。"
   - ✓ "在 A、B、C 三类设定下，该值均落在 [x, y]，与目标值 z 不相交。"
   - 后者标定了排除的**广度**，前者只表达了个人失败。

2. **给"为什么没有"一个机制方向**
   - 从"不是真物理"升级为"是可归因的工具行为/求解器伪影/设定差异"。
   - 机制假说必须可测试，并给出可观察的"指纹"（差异应出现在哪里、量级应如何）。

3. **给结论一个确定性刻度**
   - 严格证明 / 强排除（负结果）/ 机制定位（判断性，非严格证明）/ 可升级项（需外部确认）。
   - 三段式或四段式边界，让"这结论多强"一目了然。

## §5 自助检查清单（写完后逐项打勾）

- [ ] 我已用**一句话**指认研究对象/签名（①）
- [ ] 我写了**可判定的问题** + 输赢分叉（②）
- [ ] 我先**自证了工具/复现可靠**，再谈结果（③）
- [ ] 我**精确定位**了异常（哪一点/量），而非笼统"不一样"（④）
- [ ] 我**逐一**排除过替代解释，且证据从**不同路径**收敛到同一结论（⑤）
- [ ] 我**不止说"没有"**，还给了"为什么"的机制方向 + 指纹吻合（⑥）
- [ ] 我**诚实记录**了结论的演变（含反转）（⑦）
- [ ] 我给结论写了**严格措辞 + 边界声明**（⑧）
- [ ] 我**明确列出**了残留动作与未答项（⑨）
- [ ] 所有数值**取自源文件**，非凭记忆（贯穿）
- [ ] 这是把已证明事实重排因果线，**不是**为叙事编事实（贯穿）

## §7 适用范围与局限

- 九节点对**有明确异常/反常、需要排除替代解释**的研究最贴合；对纯建构性、纯理论推导类课题偏重。
- 对**纯负结果/工程复验**类课题同样适用，但节点 ⑥（机制）可能退化为"为什么无法定位机制"。
- 对**系综/统计型**课题，九节点缺少"样本规模、参数空间覆盖、筛选过程是否保证统计代表性"这一层；
  使用时应自行补一个"样本可信度"节点。
- 本准则是判断层文件：不配脚本、不进 CI；其价值在于写故事线时逐条自问，而不是事后打分。
