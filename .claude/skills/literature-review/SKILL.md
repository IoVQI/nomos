# literature-review Skill

## 触发判断

**用**：用户要产出综述**正文**（四部分：背景 → 方法/主题梳理 → 评述 → 参考文献），且**已有或可先获取候选文献清单**。
**不用**：仅需检索文献或定位片段（那是检索设施的事，不是写作设施的事）。

> 本 Skill 只负责**从清单到正文**这一段。检索与筛选由你项目的检索设施完成——
> 若没有，先让用户提供清单。**不要**因为「顺手」就去替用户做检索并直接下笔。

## 前置：候选清单

1. **搜前对齐**（🔴 强制，一次性 AskUserQuestion）：题目/范围、年份窗、来源门槛、语种配比、正文结构、交付格式（MD/Word/LaTeX）。**所有确认集中在动笔前**。
2. **清单来源**：用户提供，或由你项目的检索设施产出。清单必须能给每篇标出**它能支撑什么**（见下节分级）。
3. **本地去重**（若项目有本地文献库）：逐条 Grep 本地索引，已入库的标注路径。
   本骨架的 `project/references/` 是**空壳**，此步默认跳过。
4. **候选核验**：清单交用户确认后才进入正文撰写（可先出证据分级表）。

## 证据分级（机械约束正文）

按「拿到了什么信息」给每篇候选定级，**等级决定能写什么**：

| 级 | 判据 | 可写内容 |
|:---:|------|------|
| A | 有摘要/全文，方法/数值可核验 | 具体方法名、数据集、百分比、数值 |
| B | 仅题录（标题/作者/年份） | 只写主题归属，**禁止**具体方法/数值 |
| C | 存疑/无法核实 | 丢弃或标注「待核验」，不入正文 |

> 🔴 正文每段综述语句必须能追溯到对应论文的等级；**B 级文献写具体方法 = 违规**，当场降级或删句。
> 这条是防「凭题录编造方法细节」的唯一机械约束——不要因为「看起来合理」而放宽。

## 正文撰写（一次性成稿）

1. 按对齐的四部分骨架撰写，**不逐段停顿确认**（所有确认集中在动笔前）。
2. 每部分以**方法/主题聚类**组织，不用平铺年份流水账。
3. **转述纪律**：引用真实标题下只写该论文**实际支持**的观点；观点归属不明时标注「（待核验）」。
4. **引文格式**（GB/T 7714-2015 要点）：
   - 标点统一半角；
   - 文献类型标识：`[J]` 期刊 / `[M]` 专著 / `[C]` 会议 / `[D]` 学位论文 / `[EB/OL]` 网络资源；
   - 作者 ≤3 全列，>3 列前 3 后加「等」（英文 `et al.`）；
   - 有 DOI 则给全 DOI，无则给出可定位的出处。
   👉 完整细则以 GB/T 7714-2015 原文为准；本 Skill 只固化这几条最常被写错的。

## 交付

- 输出对话 / Markdown；Word（pandoc / python-docx）/ LaTeX 为可选交付。
- **交付说明**（🔴 强制）：B 级占比、检索局限（进不了付费库的声明）、建议补的核心文献、未完成的配图。

## 边界

- 本 Skill **不做检索**，也**不做入库**——那是另外的设施。
- 没有候选清单就没有正文：**不要**先写正文再补引用。
