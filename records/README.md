# records/ — 可选的工作台账

> 本目录是**可选的**：用于存放研究/工程过程产生的台账、报告、会话摘要与备忘录。
> 它不参与任何校验闸门，也不要求特定字段。若你的项目已有 `proposals/` 与 `coordination/`，
> 可以只用它们，把本目录当作「其他过程记录」的落点或直接删除。

## 目录约定

```text
records/
├── README.md       本文件
├── index.md        台账索引（人读；可选）
├── notes/          备忘录 / 决策记录
├── reports/        分析报告 / 审计报告
└── sessions/       会话摘要 / 交接留档
```

## 纪律

- **不复制事实**：能指向真源（代码、数据、`proposals/`、`coordination/`）的地方放指针，不抄副本。
- **不写敏感真值**：地址、凭据、个人信息用占位符；真值放在仓库外。
- **不维护计数**：需要规模信息时现场数，不在索引里写死。
- **不是产品本体**：本目录的内容默认属于过程记录，发布件可按需排除（见发布白名单）。
